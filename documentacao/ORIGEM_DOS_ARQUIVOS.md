# Origem e preservação

Esta edição foi montada a partir de duas linhas do repositório original:

| Conteúdo | Branch | Commit |
| --- | --- | --- |
| pesquisa, casos e resultados | `main` | `f3873db` |
| gateway e Donna MCP | `development_sentry` | `0efb9ae` |

O ponto comum dos branches é `18b2287`. Os arquivos científicos e as
evidências foram copiados sem reexecutar modelos e sem editar os dados brutos.

Os nomes externos foram simplificados para facilitar a navegação. Dentro de
`pesquisa/01_casos_finais/dados_canonicos/`, a estrutura original foi
preservada para permitir a conferência dos caminhos declarados no manifesto.

Credenciais, tokens OAuth, endereços privados, caches e configurações locais
não integram esta edição.
