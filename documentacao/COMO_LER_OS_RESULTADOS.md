# Como ler os resultados

Use esta ordem:

1. abra as planilhas em
   `../pesquisa/02_resultados/03_planilhas_para_leitura/`;
2. confira a interpretação oficial em
   `../pesquisa/02_resultados/01_campanha_principal/analise_final/`;
3. para auditoria, consulte as pastas `evidencia_primaria/`.

As evidências primárias são os registros preservados da execução. As análises
calculam métricas a partir desses registros. As planilhas reorganizam os
resultados para leitura humana, mas não substituem os dados primários.

A campanha principal e a extensão multimodelo são coortes diferentes. Elas
não devem ser somadas ou apresentadas como comparação causal entre modelos.
