# Controle de integridade dos 90 casos

## Propósito

Esta pasta preserva a composição técnica dos 90 casos usados na campanha final.
Ela registra 150 entradas: 60 para C1, 60 para C2 e 30 para D.

## Ordem de leitura

1. `LISTA_OFICIAL_DOS_90_CASOS.json` — composição, origem e hashes de cada
   caso e entrada;
2. `HASHES_DOS_ARQUIVOS.tsv` — hash do arquivo oficial;
3. `README.md` — explicação desta pasta.

## Fronteira

Os nomes e campos técnicos dentro do JSON foram preservados para manter a
rastreabilidade com o repositório científico original. A renomeação externa não
altera o conteúdo nem o hash do arquivo.
