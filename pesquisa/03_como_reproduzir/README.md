# Material de reprodução

Esta pasta preserva os pacotes e scripts diretamente relacionados às campanhas
incluídas nesta edição.

- `pacote_campanha_principal/`: pacote congelado da campanha original;
- `pacote_extensao_multimodelo/`: pacote usado na extensão;
- `scripts_extensao_multimodelo/`: executor e verificador da extensão;
- `scripts_analise_extensao/`: geração da análise descritiva.

Os resultados existentes são evidência preservada. Reexecutar modelos ou APIs
produz uma nova campanha e não substitui os dados incluídos aqui.
