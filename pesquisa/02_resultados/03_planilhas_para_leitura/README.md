# Planilhas para leitura dos resultados

## Conteúdo

- `RESUMO_DOS_RESULTADOS.xlsx`: resumo navegável da
  campanha M2.3 original e da extensão multimodelo.
- `RESULTADOS_DETALHADOS.xlsx`: variante detalhada da
  apresentação consolidada.

As duas planilhas são produtos derivados para consulta humana. Os dados brutos
e relatórios que sustentam a leitura estão nas pastas vizinhas das campanhas.
